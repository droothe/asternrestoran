# Astern Restoran

Astern, Anadolu mutfağından ilham alan kurgusal bir restoran markası için hazırlanmış web sitesi demosudur. Restoranın hikâyesini ve menüsünü tanıtır; ziyaretçilerin masa rezervasyonu oluşturmasına, iletişim bilgilerine ve basın içeriğine ulaşmasına imkân verir. `/admin` adresinde demo yönetim ekranı bulunur.

## Geliştirme

Gereksinimler: [Bun](https://bun.sh/)

```sh
bun install
bun run dev
```

Üretim derlemesi için `bun run build`, testler için `bun run test` komutlarını kullanın.

## Teknolojiler

React, TypeScript, Vite ve TanStack Router kullanır. Menü ve rezervasyon deneyimi bu demo uygulamasının parçasıdır; marka ve içerikler örnek amaçlıdır.
